# CHRIS CONTENT INTELLIGENCE SYSTEM
## Compact Claude Code Master Build Spec

### PURPOSE
Build a production-grade AI content operating system for the Chris Corallo personal brand.

This is not a scheduler, caption tool, or generic AI dashboard. It is an AI-operated creative organization that plans, researches, prepares, edits, quality-checks, packages, publishes, measures, learns from, and improves short-form content.

Target operating volume: ~30 original videos/week distributed across Instagram Reels, TikTok, and YouTube Shorts (~90 placements when appropriate).

Primary objective:
> Maximize long-term attention, recognition, trust, audience quality, brand equity, and economic value of the Chris Corallo personal brand while preserving authenticity, factual integrity, creative quality, and sustainable production.

Do NOT optimize only for views.

# 1. PRODUCT PHILOSOPHY

Chris should spend time on thinking, learning, building expertise, living experiences worth discussing, forming opinions, filming, relationships, actual business/career work, and high-value creative decisions.

The system should increasingly handle research prep, planning, content organization, repetitive editing, rendering, captions/graphics, QC, scheduling, platform packaging, publishing, analytics, comments, experimentation, learning, and institutional memory.

Core principle:
> Eliminate everything that prevents Chris from being the valuable part.

Premium means correct, intentional, reliable, context-aware, polished when appropriate, restrained when appropriate, factually defensible, simple for Chris, scalable, and not obviously AI-generated.

Premium does NOT mean maximum complexity or maximum editing.

# 2. BRAND CONSTITUTION

Chris Corallo is the umbrella personal brand.

Finance is currently the strongest expertise/skill pillar, but Chris must not become permanently trapped as “Finance Guy.”

Money Has Issues is newsletter/editorial IP under Chris.

Monday Money Meetup is an event/community property.

Potential franchises:
- Show Me The Numbers
- Why Does Money Work Like This?
- Building Chris / build-in-public

Audience:
> Ambitious people broadly in their 20s and 30s trying to get their shit together without pretending they already understand everything.

Working ethos:
> Stop pretending you understand shit you don’t. Ask better questions, look at the actual numbers, and build a better life intentionally.

Pillars:
1. Skill — finance, money, debt, credit, investing, retirement, insurance, business/practical adulthood
2. Mindset — skepticism, ambition, decisions, money psychology, growth
3. Lifestyle — career, business building, LA/life, gym, content journey, wins/failures
4. Passions — authentic interests that naturally become part of Chris

Principles:
- Human > synthetic
- Specific > generic
- Interesting > merely informative
- Clear > sophisticated-sounding
- Personality + expertise > information alone
- Evidence > guru folklore
- Real numbers > vague claims
- Brand equity > temporary virality
- Original identity > copying creators
- Correct restraint > unnecessary production

# 4. SYSTEM ARCHITECTURE

Do NOT implement as many agents freely chatting.

Use one Creative Director / Orchestrator with specialist components that communicate via structured persisted artifacts.

Specialists return typed outputs such as:
- WeeklyProgrammingThesis
- ProductionContract
- ResearchPacket
- CreatorCard
- ScriptPackage
- EditPlan
- QCReport
- PlatformPackage
- PerformanceSnapshot
- BeliefProposal

Use agents for semantic judgment.
Use deterministic code for deterministic tasks.
Use subagents only where specialization, isolation, parallelism, or independent review materially helps.

# 5. AUTHORITY HIERARCHY

1. Human owner (Chris)
2. Hard gates
3. Brand Constitution
4. Current strategic direction
5. Creative Director
6. Strong first-party Chris evidence
7. Specialist domain guidance
8. Reference creator patterns
9. Generic industry assumptions

Hard gates may BLOCK publication:
- factual failure
- severe technical failure
- security issue
- invalid platform state
- required compliance failure
- missing final media
- unresolved blocking QC

Creative quality cannot average away a hard failure.

Learning agents may propose changes but may not automatically rewrite constitutional truth.

# 6. MEMORY

Maintain four memory types:

Constitutional Memory — what the brand is.

Episodic Memory — every idea, video, take, edit, publication, metric snapshot, comment, and human override.

Semantic Memory — what the system currently believes. Every belief must include statement, evidence, sample size, platform/context, date range, confidence, confounders, contradictory evidence, first/last evaluated, retest conditions, and status.

Strategic Memory — where the brand is intentionally going.

Historical performance must not trap future brand direction.

# 7. REQUIRED INTELLIGENCE STORES

## Evidence Ledger
Every learned rule needs provenance. Never store “AI thinks this works” without evidence.

## Decision Journal
Store question, selected decision, alternatives, rationale, evidence, confidence, decision owner, model/prompt version, human override, later outcome, and retrospective.

## Brand Timeline
Track what historically worked, what works now, and where the brand is intentionally going.

## Human Taste Model
Learn Chris’s preferences from edits/rejections such as too corny, too corporate, too AI, too busy, too much B-roll, love this framing, sounds like me, doesn’t sound like me, leave it raw.

Do not convert one preference into a universal rule.

## Content Graph
Track derivative_of, remake_of, inspired_by, same_topic_as, same_hook_family, same_format_family, experiment_variant_of, newsletter_related, reference_influenced_by.

# 9. CANONICAL WEEKLY WORKFLOW

1. Weekly Review — collect prior metrics, audience response, experiments, production cost, and human overrides.
2. Weekly Programming Thesis — one concise strategic truth binding the week.
3. Portfolio Design — build ~30 videos as one coherent portfolio across acquisition, authority, relationship, brand expansion, conversion, finance/personality, formats, production tiers, experiments, MHI alignment, evergreen/time-sensitive balance, and production burden.
4. Production Contract — each video gets purpose, core idea, audience promise, topic, format, tier, target length, research depth, factual risk, experiment, platform opportunity, edit budget, required assets, scope, and DO_NOT_EXPAND_INTO.
5. Research — FACTS → SCRIPT for factual finance content. Return primary claim, facts, sources, numeric inputs, caveats, contradictory evidence, unsupported claims, confidence, STOP_RESEARCHING.
6. Claims Gate — independent factual review: PASS / PASS_WITH_REQUIRED_EDIT / BLOCK.
7. Script — spoken delivery, one central promise, default HOOK / BEAT 1 / BEAT 2 / BEAT 3 / PAYOFF when useful.
8. Creator Card — only what Chris needs to film.
9. Film Queue — batch by setup; no research during filming unless the current claim becomes invalid.
10. Raw Media Ingestion — store originals; generate transcript, metadata, scene/audio/visual analysis, and take groups.
11. Take Selection — choose best take based on accuracy, clarity, energy, pacing, framing, audio, runtime, editability.
12. Edit Plan — LLM decides; renderer executes. Specify cuts, captions, headline, typography, positions, punch-ins, reframing, graphics, charts, B-roll, music, SFX, transitions, AI visuals, duration, and variants.
13. Render — deterministic media tools.
14. Visual QA — inspect actual render over time for face/eye/mouth obstruction, title/caption collision, crop, safe zones, wrapping, legibility, contrast, charts/numbers, first-frame comprehension, artifacts, and tier appropriateness.
15. Auto Repair — EDIT → RENDER → INSPECT → FIX → RENDER → REINSPECT with iteration limits.
16. Hard Gates — FACTUAL PASS, TECHNICAL PASS, BRAND threshold, CREATIVE threshold.
17. Platform Preview — simulate IG/TikTok/YouTube safe areas; prefer one master + lightweight variants.
18. Weekly Assembly — use Content Vault backups if one asset fails.
19. Auto-Fill Week — schedule coherently using topic spacing, format spacing, tone, funnel role, experiments, newsletter timing, platform evidence, and content expiry.
20. Platform Packaging — generate after final render.
21. Preflight — verify file/version/hash, credentials, account, packaging, schedule, media spec, approval, no block, idempotency key.
22. Publish + Verify — store platform, post ID, URL, timestamp, exact packaging, media hash, response.
23. Metric Snapshots — where available: T+1h / 6h / 24h / 72h / 7d / 30d.
24. Audience Intelligence — classify comments and convert strong signals into follow-up content, script improvements, FAQ, newsletter ideas, and community lessons.
25. Performance Evaluation — track attention, consumption, amplification, conversation, identity conversion, relationship, business outcome, production ROI.
26. Learning — separate OBSERVATION from CAUSAL CLAIM from EXPERIMENTAL EVIDENCE.
27. Next Week — accepted learnings feed the next Weekly Programming Thesis.

# 16. COST & MODEL ROUTING

LOW/HIGH-VOLUME:

DETERMINISTIC:
normal software, not LLMs.

# 21. GRACEFUL FAILURE

If reference monitoring fails → production continues.
If one video fails → use vault backup.
If one platform fails → others continue.

If one provider fails → safe fallback when possible.

The system must fail elegantly.
