# Chris Voice Samples

**Status: EMPTY — for Chris to fill.** Nothing below the `SAMPLES START` marker has been
written yet. The system deliberately ships with zero samples rather than invented ones: a fake
"real Chris transcript" would teach every agent the wrong voice with false authority.

## Why this file exists

The Brand Constitution and Chris Brain describe Chris's voice in adjectives ("direct,
skeptical, plain English"). Agents write much closer to a real voice when they can also read
how Chris actually talks. Once this file contains samples, every agent that receives brand
context (Script, Brand Guardian, Creative Director, Production Director, Platform Packaging,
...) gets them automatically — no code change needed.

## How to fill it (instructions for Chris)

1. Paste 3–8 **real, verbatim transcripts** of videos (or voice memos) where you sound most
   like yourself. Raw transcripts beat polished scripts — keep the "um, look," and the
   occasional profanity if that's how you talk.
2. One sample per `### ` heading. Under each heading add one line: platform/date, and why it's
   representative (e.g. "my best hook delivery", "how I explain a number").
3. Optionally add a short sample labelled `NOT ME` showing copy you'd reject (corporate, hype,
   generic AI). Label it clearly — agents treat it as a counter-example.
4. Keep the total under ~3,000 words; more isn't better, representative is better.
5. Everything goes **between** the two markers below. Text outside the markers is ignored.
6. Committing a change to this file is a brand decision — note it in /docs/DECISIONS.md like
   any other change under /brand.
